Questions

What happens when my credits run out?

AI requests pause until the month resets, you get a top-up, or you connect your own API key. Your documents stay fully editable; only AI usage is metered.

Will Squire Docs stay free?

It's free while we finish the product in public beta. If that changes, you'll get clear notice first, and your documents export as markdown at any time. The open source project is MIT licensed.

Do I need a credit card?

No. Sign in with Google and start writing. No card required during the beta.

What happens to my documents if I stop using Squire Docs?

They're yours. Every doc exports as portable markdown, and repo sync means your content can already live in your own git repository. There's no export fee and no lock-in.

Can we run Squire Docs ourselves?

Yes. Squire Docs is open source under the MIT license. Install it with one command, or follow the self-host guide. If you want us to run a dedicated instance for you in the cloud region of your choice, email contact@squiredocs.com.

Is the hosted version the same software?

Yes. squiredocs.com runs the same code as the public repository.

Where can a managed instance run?

In the cloud region you choose, including EU regions. Your documents, database, and backups stay in that region, which helps you meet data residency and sovereignty requirements. Email contact@squiredocs.com to discuss your region.

Do I need an API key to self-host?

No. The editor, version history, repo sync, and agent connection work without one, because your own agent brings the AI. Add a key to turn on the built-in assistant and semantic search.
