Docs your agents can edit with you.

Squire Docs is an open source collaborative editor for people and AI agents. Connect Claude Code, Codex, or any MCP agent, watch its edits land live, and keep everything in sync with markdown in your repo.

Your agent, live in the document

Your agent connects over MCP, shows up as a named cursor, and edits the document while you watch. You and the agent can type in the same paragraph at the same time, and both edits survive.

Live presence for people and agents

Every collaborator shows up as a named, colored cursor, including your coding agents.

Edits land as they happen

Watch the agent's changes appear while it works, and correct the draft before it finishes.

Built for simultaneous edits

People and agents edit at the same time and changes merge automatically, with no locks or conflict dialogs.

See what changed, undo what you don't want

Every change, human or agent, is attributed to whoever made it, and each version can be restored. Diff highlighting and version history show you what the agent changed.

Markdown in, markdown out, synced to your repo

Import any markdown, export .md, and keep a two-way sync with the files in your repo. A push from the repo merges like an edit from a collaborator who was offline: attribution intact, no conflict dialogs. GFM task lists, tables, and mermaid diagrams render natively.

Bring your markdown in

Paste or import existing .md files and your agent's markdown output. They become collaborative, attributed documents.

Export markdown

Every doc exports as portable .md at any time.

Two-way repo sync

Frontmatter carries each doc's identity, so a spec stays in sync between Squire Docs and your repo. Edit in either place; changes merge cleanly.

Run it on your machine

With Docker installed, tell your agent "set up Squire Docs locally." It runs the install script, prints a sign-in link, and connects itself. Two clicks and you have your own instance on localhost, with no accounts or API keys to configure.

curl -fsSL https://squiredocs.com/install.sh | sh

What people use it for

Squire Docs holds the documents your agents write and your team reads.

Specs and design docs

For spec-driven development: the spec your team edits and your coding agent implements against, synced to the repo so spec-kit, Kiro, or your own tooling reads the same file.

Agent plans and handoffs

The plan your agent writes before it codes, in a place where you can edit it before saying go, and where the next session (or the next agent) can pick it up.

Research and reports

Long agent output you want to read, mark up, and keep, instead of scrolling a terminal.

Team knowledge your agents maintain

Runbooks, ADRs, and onboarding docs that agents update as the code changes, with a record of who changed what.
