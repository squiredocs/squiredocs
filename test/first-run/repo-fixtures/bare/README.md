# color-utils

A small library of color-space conversion helpers (RGB, HSL, OKLCH). Utility
code, no spec/design/plan documents.

Fixture repo for the Squire Docs first-run sign-off matrix (nothing-spec-shaped
shape): with no `.kiro/specs/`, `specs/`, `PLAN.md`, `docs/plan.md`, or
`CLAUDE.md`, the `/squire:onboard` flow should offer to draft a starter spec
from this README and the repo structure.
