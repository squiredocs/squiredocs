# cron-runner

A tiny scheduled-job runner. No `specs/` or `.kiro/specs/` — the project's
working agreement lives in `CLAUDE.md`.

Fixture repo for the Squire Docs first-run sign-off matrix (`CLAUDE.md` shape):
with nothing higher-precedence present, the `/squire:onboard` flow should offer
`CLAUDE.md` as the spec candidate (lowest precedence before a starter spec).
