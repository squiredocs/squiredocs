Welcome! Let's get you connected to Squire Docs.

Signing in creates your Squire Docs account automatically — there is no separate signup step.

To connect, open your browser and approve access at this authorization URL:

https://squiredocs.com/mcp/auth/authorize?client_id=client_abc&code_challenge=xyz&state=123

If the localhost callback fails (it won't reach a server in this environment),
that's expected — just copy the code from the browser and paste it back here.

Great — the client will silently reconnect and continue right where we left off,
no need to restart anything.

Now, to sync your existing spec file, we use the byte-channel: the file is moved
over HTTP with curl and an sk_sqd_ token, never re-typed through a tool parameter.

  curl -H "Authorization: Bearer sk_sqd_..." --data-binary @spec.md https://squiredocs.com/mcp/import

Done. Here is your document:

https://squiredocs.com/d/9f3c2a71-doc

From now on the standing loop is: read the spec before you start, and write your
changes back after — that read-spec-before / write-back-after habit is how we stay in sync.
