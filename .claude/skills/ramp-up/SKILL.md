Ramp up on this application before doing any work.

1. Read `README.md` in the project root. This is the core source of documentation
   about the app — its purpose, architecture, and how the pieces fit together.

2. Read `docs/dev.md`. This covers the local development environment, including how
   to run commands in Minikube via the app dev pod (which is generally already set up
   and ready to go).

3. Skim the rest of `docs/` for any topics relevant to the task at hand (auth, MCP
   integration, permissions, testing, etc.).

After reviewing, give the user a brief summary of what the application does and how
the local dev environment works, then ask what they'd like to work on.
