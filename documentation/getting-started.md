This page covers signing in, the welcome document you land on the first time, and creating and finding documents.

## Signing in with Google

Google is the only sign-in method. Click Sign up with Google (or Sign in with Google on a return visit) and authorize with your Google account. There is no password to set and no separate account to create. Your session is kept in secure cookies, so you stay signed in across visits.

You can also arrive through a coding agent: when an agent such as Claude Code connects to Squire Docs over MCP, its connect link opens a single "Connect to Squire Docs" screen where you continue with Google and grant the agent access. Signing up this way creates your account in the same step. You can revoke an agent's access anytime in Settings under AI Agent Access. See [Agents and MCP](/documentation/agents-and-mcp).

## Your welcome document

The first time you sign in through the browser, Squire Docs creates a personal "Welcome to Squire Docs" document that you own. You land on it with the AI assistant panel open, and the assistant greets you and invites you to bring the markdown you already have: drag a `.md` file into the chat, or paste markdown there, and it becomes a document. The welcome document itself shows how the pieces of Squire Docs fit together and how to connect coding agents over MCP. Each user gets their own copy of this document. Nothing about it is shared. (If your account was created by connecting an agent rather than in the browser, no welcome document is made.)

You keep landing on the welcome document each time you sign in until you are "engaged", which means you own another document that has content in it, whether you created it yourself or an agent created it for you. Once you are engaged, sign-ins take you to your document list instead.

## Creating documents

Create a document from the document list. A new document opens in the editor with a title field at the top and the formatting toolbar below it. Press Tab from the title to move focus into the document body.

You can also create documents from the AI assistant: ask it to create one, or drag a `.md` file into the chat to import it as a document (see [Markdown](/documentation/markdown)). External agents can create documents too, over the Model Context Protocol. See [Agents and MCP](/documentation/agents-and-mcp).

## Finding documents

The document list shows the documents you can access. A filter above the list narrows it to All documents, Owned by me, or Shared with me. Each row shows when the document was last opened or edited (by you, a collaborator, or an agent) and carries badges for sharing: green means a document shared with you, purple means a document you shared with others. A three-dot menu on each row offers Share and Delete.

The list refreshes on its own every five seconds and when you return to the browser tab. You can also click the document icon next to the "Documents" title to refresh it.

To find a document by its contents rather than its title, use the search box on the document list. Matching rows show a highlighted snippet of the matching passage. See [Search](/documentation/search).
